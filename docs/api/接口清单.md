# API 接口清单

> 最后更新：2026-06-06

## 通用规范

- **Base URL**: `http://localhost:8080/api/v1`
- **Content-Type**: `application/json`
- **认证方式**: `Authorization: Bearer <access_token>`
- **统一响应格式**:
  ```json
  { "code": "OK", "message": "success", "data": {}, "traceId": "uuid" }
  ```
- **分页格式**（游标）:
  ```json
  { "items": [], "nextCursor": "...", "hasMore": true }
  ```

## 共享类型定义

> 详见 `packages/shared-types/src/index.ts`

### ApiResponse\<T\>
| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 状态码，成功为 `OK` |
| message | String | 提示信息 |
| data | T | 业务数据 |
| traceId | String | 链路追踪 ID |

### PaginatedResponse\<T\>
| 字段 | 类型 | 说明 |
|------|------|------|
| items | T[] | 数据列表 |
| nextCursor | String\|null | 下一页游标 |
| hasMore | Boolean | 是否有更多 |
