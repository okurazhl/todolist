# 智能备忘录系统开发需求

## 1. 项目概述

本项目为智能备忘录系统，支持手机、平板、PC、Web、蓝牙硬件和语音输入等多端接入。系统核心能力包括语音识别、AI 语义处理、备忘录管理、多端同步、蓝牙设备管理、消息推送、文件存储和全文搜索。

系统整体分为三层：

| 层级 | 组件 | 说明 |
| --- | --- | --- |
| 接入层 | 手机 / 平板 / PC / Web / 蓝牙硬件 / 语音输入 | 多端统一接入，负责用户交互、语音采集、蓝牙数据接收 |
| 服务层 | ASR / AI 语义处理 / 备忘录 / 同步 / 蓝牙管理 / 推送 | 核心业务逻辑，提供接口、智能处理、同步和消息能力 |
| 数据层 | 用户库 / 备忘录库 / 同步状态 / 文件存储 / Redis / Elasticsearch | 数据持久化、缓存、搜索和附件存储 |

## 7. 开发任务流程

### 7.1 需求分析阶段

- 明确端侧范围：手机、平板、PC、Web、蓝牙硬件、语音输入。
- 梳理核心用户场景：文字备忘、语音备忘、AI 摘要、待办提醒、多端同步、蓝牙录入。
- 输出 PRD、业务流程图、数据流图、接口清单、权限模型。

### 7.2 技术选型阶段

- 确定前端框架、后端框架、数据库、ASR 方案、AI 模型、推送方案、蓝牙协议。
- 明确是否支持私有化部署、本地 ASR、本地大模型。
- 输出技术架构文档、技术选型说明、开发规范。

### 7.3 原型与 UI 设计阶段

- 设计备忘录首页、录音入口、AI 摘要、标签分类、搜索、同步状态、设备管理页面。
- 设计移动端、平板端、PC 端、Web 端的响应式交互。
- 输出 Figma / Axure 原型、UI 标注、交互说明。

### 7.4 基础工程搭建

- 建立前端、后端、AI 服务、网关、数据库、Redis、MQ、ES、MinIO 项目骨架。
- 配置 Docker Compose、本地环境变量、日志格式、Swagger、CI 流程。
- 建立代码规范、提交规范、分支规范和接口版本管理规则。

### 7.5 用户与鉴权模块开发

- 实现注册登录、Token、刷新令牌、退出登录。
- 实现设备绑定、设备列表、设备注销。
- 实现 API 鉴权、权限校验、接口限流。

### 7.6 备忘录核心模块开发

- 实现备忘录新增、编辑、删除、查询。
- 实现分类、标签、置顶、归档、软删除。
- 实现附件上传、版本记录、操作日志。

### 7.7 语音输入模块开发

- 实现录音上传、本地 ASR 或云端 ASR 调用。
- 实现语音转文字、识别结果回填备忘录。
- 支持长音频异步识别和识别状态查询。

### 7.8 AI 语义模块开发

- 实现自动摘要、标签推荐、待办事项提取。
- 实现意图识别、语义搜索、内容分类。
- 对 AI 请求增加超时、重试、降级和成本统计。

### 7.9 同步模块开发

- 实现多端登录、增量同步、同步游标。
- 实现 WebSocket 长连接和同步事件分发。
- 实现冲突检测、冲突合并策略、离线编辑回放。

### 7.10 蓝牙模块开发

- 实现 BLE 设备扫描、连接、配对、解绑。
- 实现蓝牙数据接收、断线重连、设备状态同步。
- 完成不同手机系统和蓝牙硬件的兼容性测试。

### 7.11 推送模块开发

- 接入 APNs、FCM、WebSocket。
- 实现备忘录提醒、同步通知、设备状态通知。
- 支持推送开关、免打扰、失败重试和推送回执。

### 7.12 搜索与索引模块开发

- 接入 Elasticsearch / OpenSearch。
- 实现标题、正文、标签、分类的全文搜索。
- 支持搜索索引异步更新和重建。

### 7.13 测试阶段

- 执行单元测试、接口测试、端到端测试。
- 执行蓝牙兼容性测试、弱网同步测试、离线编辑测试。
- 执行并发测试、压力测试、安全测试和数据恢复测试。

### 7.14 部署上线阶段

- 配置生产数据库、缓存、MQ、对象存储、HTTPS。
- 配置监控告警、日志收集、链路追踪、自动备份。
- 先进行灰度发布，再逐步全量上线。

### 7.15 运维与迭代阶段

- 监控接口耗时、ASR 成功率、AI 调用成本、同步失败率、推送到达率。
- 持续优化识别准确率、同步体验、搜索效果和跨端一致性。
- 根据用户反馈迭代标签体系、提醒能力、AI 摘要质量和蓝牙设备兼容性。

## 8. 开发优先级建议

## 10. 风险与注意事项

| 风险 | 说明 | 建议 |
| --- | --- | --- |
| ASR 准确率不足 | 嘈杂环境、方言、长音频会影响识别质量 | 支持多 ASR 供应商切换，保留人工编辑能力 |
| AI 成本过高 | 摘要、分类、语义搜索可能产生大量模型调用 | 增加缓存、限流、批处理和模型降级策略 |
| 多端同步冲突 | 离线编辑和多设备同时编辑可能产生冲突 | 设计版本号、更新时间、冲突合并和用户确认机制 |
| 蓝牙兼容性问题 | 不同硬件、系统版本、权限策略差异较大 | 建立蓝牙设备白名单和兼容性测试矩阵 |
| 推送到达不稳定 | 不同平台推送策略不同，厂商限制明显 | APNs、FCM、WebSocket、厂商推送组合使用 |
| 数据安全风险 | 备忘录可能包含隐私和敏感数据 | 加密传输、敏感字段加密、权限控制、审计日志 |

## 13. MVP 验收标准

- 用户可以在移动端或 Web 端创建、编辑、删除和查询备忘录。
- 用户可以上传语音并生成文字内容。
- 系统可以对备忘录内容生成摘要和推荐标签。
- 同一账号在两个端之间可以完成基础数据同步。
- 系统可以保存录音或图片附件。
- 基础接口具备鉴权、限流、日志和异常处理。
- 本地开发环境可以通过 Docker Compose 一键启动核心依赖。
