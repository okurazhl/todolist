# TodoList 悬浮小工具

一个使用 Python + Tkinter 编写的桌面悬浮 TodoList。

## 功能

- 始终置顶、半透明、无系统标题栏
- 自定义顶部栏，支持拖动窗口
- 常态 / 放大 两种 UI
- 右上角菜单可调透明度、字号大小、窗口宽度和窗口高度
- 右下角可拖拽调整页面大小
- 添加待办事项并设置完成时间
- 到达完成时间后弹出提醒
- 单颗优先级圆点，颜色由浅到深表示优先级
- 勾选完成、删除单条任务、清除已完成任务
- 放大模式下查看历史任务，包含任务内容、设定时间、目标时间、完成时间

## 运行

```bash
python main.py
```

完成时间格式：

```text
YYYY-MM-DD HH:MM
```

任务数据会保存在当前目录的 `tasks.json` 中。
